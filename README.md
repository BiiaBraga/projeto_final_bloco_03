# 💊 Farmácia Frontend

Interface web desenvolvida para o sistema de gerenciamento de farmácia.

O **Farmácia Frontend** é uma aplicação React criada para consumir a API da Farmácia e fornecer uma interface visual simples, moderna e organizada para o gerenciamento das informações do sistema.

Este projeto foi desenvolvido com foco em componentização, responsividade e boas práticas no desenvolvimento frontend.

---

# 📌 Sobre o projeto

A aplicação foi construída utilizando React com Vite e possui integração com a API desenvolvida no backend.

O sistema tem como objetivo facilitar o gerenciamento de categorias e produtos da farmácia através de uma interface intuitiva e de fácil utilização.

# ⚙️ Instalação

Clone o repositório:

```bash
git clone https://github.com/BiiaBraga/projeto_final_bloco_03.git
cd projeto_final_bloco_03
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```
